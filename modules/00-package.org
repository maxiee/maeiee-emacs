#+TITLE: 00 包管理：建立可重复安装的基础
#+PROPERTY: header-args:emacs-lisp :results silent :comments link
#+STARTUP: overview

* 本章目标

让一台只有 GNU Emacs 的新机器能够自动获得后续章节使用的软件包。这里选用 Emacs 自带的 =package.el= 与 =use-package=，先把依赖保持在最少。

* 需要理解的概念

- =package.el= 负责从软件包仓库下载、安装和激活扩展。
- =use-package= 负责用声明式结构描述“何时加载、怎样配置、绑定什么键”。
- GNU ELPA、NonGNU ELPA 与 MELPA 分工不同；本配置按此顺序声明。

* 配置

#+begin_src emacs-lisp
(require 'package)

(setq package-archives
      '(("gnu"    . "https://elpa.gnu.org/packages/")
        ("nongnu" . "https://elpa.nongnu.org/nongnu/")
        ("melpa"  . "https://melpa.org/packages/")))

(package-initialize)

(defconst maeiee-var-directory
  (expand-file-name "var/" user-emacs-directory))
(make-directory maeiee-var-directory t)

;; 只在新环境第一次启动时刷新索引，避免以后每次启动都访问网络。
(let ((marker (expand-file-name "package-archives-ready" maeiee-var-directory)))
  (unless (file-exists-p marker)
    (condition-case err
        (progn
          (package-refresh-contents)
          (with-temp-file marker
            (insert (format-time-string "%FT%T%z\n"))))
      (error
       (display-warning
        'maeiee-emacs
        (format "Package archive refresh failed: %s"
                (error-message-string err))
        :warning)))))

(require 'use-package)

(setq use-package-always-ensure t
      use-package-verbose init-file-debug
      use-package-compute-statistics t)
#+end_src

* 动手验证

1. 首次启动时观察 =*Messages*=，应能看到软件包索引刷新。
2. 执行 =M-x list-packages=，确认 GNU、NonGNU 与 MELPA 条目可见。
3. 以后想主动刷新索引，执行 =M-x package-refresh-contents=。
