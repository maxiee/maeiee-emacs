#+TITLE: 80 Org Mode：笔记、配置与未来电子书的共同底座
#+PROPERTY: header-args:emacs-lisp :results silent :comments link
#+STARTUP: overview

* 本章目标

建立适合文学编程的 Org 默认行为，为 Org 增加可与原生键位并用的 Evil
结构导航，并提供打开目录、tangle、重载等日常命令。

* Org 基础语法与导航

Org 最重要的特点是：普通文本通过少量标记获得结构。先掌握标题、折叠、
列表、链接和表格，就能阅读和维护大多数 Org 文档。下面的内容按日常使用
频率排列，适合作为快速回顾；每项操作同时说明原生 Emacs 键位和本配置中
可用的 Evil 键位。

** 标题与层级

用一个或多个星号表示标题层级。星号越多，层级越深。

#+begin_example
,* 第一章
,** 第一节
,*** 小节
,* 第二章
#+end_example

示例行开头的逗号是 Org 的转义符：它阻止星号被当前文档识别为标题，导出
时不会出现在示例内容中。

标题下的正文属于这个标题，直到遇到同级或更高层级的下一个标题。Org 的
目录、折叠、Agenda 和导出功能都依赖这套层级结构。

把标题当作“可移动、可折叠、可重组的容器”，而不是带星号的普通行。这里不
需要在原生 Org 与 Evil 之间二选一：原生 =C-c= 前缀提供完整、可发现的结构
命令；Evil normal state 则承接高频的就地浏览和编辑。两者共用同一份大纲，
因此可以按下列分工连续使用。

*** 导航与浏览：先找到要处理的结构

- 在标题之间移动时，Evil normal state 使用 =C-j= / =C-k=；它们只跳转到
  下一个 / 上一个可见标题。需要使用任何 Emacs 环境都一致的键位时，使用
  =C-c C-n= / =C-c C-p=。
- 在当前标题的关系中移动：=C-c C-f= / =C-c C-b= 前往下一个 / 上一个同级
  标题，=C-c C-u= 回到父级标题。读完一个小节后要继续读同层内容时，同级
  移动通常比反复上下跳转更自然。
- =TAB= 折叠或展开当前标题，=S-TAB= 循环整篇文档的可见层级。折叠后仍可用
  前述标题命令浏览，这使长文档可以像目录一样阅读。
- 不知道目标在哪时，用 =C-c C-j= 按标题路径跳转；需要只查看一组相关标题时，
  用 =C-c /= 建立稀疏树。它们比滚动查找更适合大纲文档。

这里的 =C-j/C-k= 有意不承担普通文本移动的职责：本配置保留 =gj/gk= 给
=evil-org= 的 Org element 导航。后者会在段落、列表项、表格行或源码块之间
移动，适合浏览一个标题内部；前者用于在章节之间切换。先用 =C-j/C-k= 找到
容器，再用 =gj/gk= 处理容器里的内容，动作就不会互相混淆。

*** 编辑与调整：先写内容，再塑造结构

- 想到新的并列主题时，在合适位置按 =M-RET= 插入同级标题；它会保留当前位置
  的大纲语境。需要立刻进入任务流时，用 =M-S-RET= 插入 TODO 标题。
- 已写成普通行或列表项、后来才发现它应该成为一节时，用 =C-c *= 将当前位置
  转换为标题。这个“先记下、后归类”的动作比一开始就纠结层级更流畅。
- 调整标题的归属使用 =M-LEFT= / =M-RIGHT= 提升或降低层级。在 Evil normal
  state 中，=< / =>= 是相同的高频操作，=M-h/l= 也是可用的方向键替代；这些
  键位在列表和表格中同样遵循 Org 的上下文语义，所以先确认光标位于标题上。
- 调换章节顺序时，使用 =M-UP= / =M-DOWN= 移动当前标题及其完整子树；Evil
  normal state 中可用 =M-k/j=。移动的是整段结构而非单行，链接、正文和子
  标题会一起保留。
- 内容需要进入另一处既有结构时，用 =C-c C-w= refile 当前条目；完成且不再
  需要出现在工作文档中的子树，可用 =C-c C-x C-a= 按默认位置归档。前者用于
  重组，后者用于保持当前文档聚焦。

日常文字编辑仍优先沿用 Evil：用移动、文本对象和操作符处理标题正文；在
列表项或表格行上，=o= / =O= 会按 Org 规则在下方 / 上方续写同级项并进入
insert state。也就是说，Evil 负责手感一致的局部编辑，Org 命令负责不会破坏
大纲的结构变化。遇到不常用操作时，回到原生 =C-c= 前缀即可，而不必记住每个
Evil 映射。

** 折叠与展开

折叠是当前缓冲区的一种阅读视图。把长文档保持为紧凑的大纲，按需要展开一条分支，能同时保留全局方向和局部注意力。标题导航只在可见标题之间移动，因此折叠状态本身就是浏览路线的一部分，而不只是视觉整理。

*** 局部折叠：把一个标题当作可缩放的容器

将光标放在标题行首，按 =TAB= 会在三个层次间循环：

1. 仅显示当前标题；
2. 显示当前标题及其直接子标题；
3. 显示完整子树，包括正文和所有后代标题。

第二种状态尤其适合先看一章的目录，再挑一个小节继续展开。Evil normal state 中，=TAB= 与 =g TAB= 都执行这一操作；不必为同一个概念切换手感。

如果 =TAB= 没有折叠标题，先检查光标是否位于标题行首：在表格中它会移动到下一单元格，在普通文本中则遵循该处的缩进或局部编辑规则。

*** 全局折叠：先选择阅读尺度，再进入局部

=S-TAB= 或 =C-u TAB= 循环整篇文档的三种视图：仅顶层标题、所有标题但不显示
正文、显示全部内容。打开陌生或很长的文档时，先停在“所有标题”视图，借助
=C-j/C-k= 或 =C-c C-n/p= 找到相关章节，再对该章节按 =TAB= 展开，通常比从头
滚动更快。

需要回到文件设定的初始可见性时使用 =C-u C-u TAB=；需要连抽屉内容也全部
显示时使用 =C-u C-u C-u TAB=。这些是恢复视图的命令，不是日常阅读必须记忆的
快捷键。

*** 与导航、搜索和专注编辑配合

- 折叠后，=C-j/C-k= 与 =C-c C-n/p= 仍可在当前可见的标题之间跳转；要进入被
  折叠分支的下一层，先用 =TAB= 展示它的直接子标题，再继续导航。
- 搜索或跳转已经把光标带到隐藏上下文时，=C-c C-r= 会展开光标周围必要的大纲
  路径。它适合“我已经找到了，但看不清上下文”的情况。
- 折叠用于保留全局上下文；需要暂时把编辑、搜索和命令限制在一个子树内时，
  再使用 =C-x n s= 收窄到当前子树，完成后以 =C-x n w= 恢复。不要把收窄当成
  普通折叠：前者改变当前缓冲区可操作的范围，后者只改变显示层级。

一个顺手的节奏是：全局概览定位章节，局部展开阅读或修改，完成后折回标题，
再跳到下一个可见分支。Evil 提供连续的移动手感，Org 则确保每次展开、收起
和移动都仍然围绕文档结构进行。

** 段落、换行与特殊文本

连续的普通行属于同一个段落。空行开始一个新段落；单纯按 =RET= 换行不一定
会产生新的段落。

#+begin_example
这是第一段的第一行。
这是第一段的第二行。

这是第二段。
#+end_example

常用的轻量标记：

- =*粗体*=、=/斜体/=、=_下划线_=、=+删除线+=。
- =~等宽文字~=、=会显示为代码=、=\_{}= 等特殊字符用 Org Entity 表示。
- =C-c C-x C-f=：插入或修改当前文字的强调标记。
- 本仓库通过 =org-hide-emphasis-markers= 隐藏强调标记；需要查看原始标记时可暂时关闭该变量。

** 列表与复选框

无序列表使用 =-=、=+= 或 =*=；有序列表使用 =1.= 或 =1)=。

#+begin_example
- 无序项目
  - 嵌套项目
- 第二个项目

1. 第一步
2. 第二步

- [ ] 待读
- [X] 已完成
#+end_example

常用操作：

- =M-RET=：插入同级列表项。
- =M-S-RET=：插入带复选框的列表项。
- =C-c C-c=：切换复选框状态。
- =S-LEFT/RIGHT=：切换复选框或 TODO 状态。

启用 =evil-org= 后，normal state 中 =o= / =O= 会在当前列表项下方或上方插入
同级项目，并自动进入 insert state。

列表适合表达步骤和清单；如果项目需要日期、状态或 Agenda 管理，通常应
升级为标题和 TODO 项。

** 链接

最常见的链接形式是 =[[地址][显示文字]]=；省略显示文字时，地址本身会显示。

#+begin_example
[[https://orgmode.org][Org Manual]]
[[file:../README.org][项目说明]]
[[file:../modules/80-org.org::*Org Babel][本章 Babel 小节]]
#+end_example

常用操作：

- =C-c C-l=：插入或编辑链接。
- =C-c C-o=：打开当前链接。
- =C-c C-x C-v=：显示或隐藏当前文档中的行内图片。
- =C-c &=：跳回最近一次打开的 Org 链接位置。

文件链接尽量使用相对路径；同一仓库中的文档移动后，要检查链接是否仍然
有效。标题链接适合快速跳转，稳定引用则可以进一步使用 =CUSTOM_ID= 或
=org-id=。

** 表格

以竖线开头的连续行会被识别为表格。输入一行并按 =TAB=，Org 会自动调整
列宽；在表格最后一行按 =TAB=，可以创建新行。

#+begin_example
| 项目 | 状态 | 备注 |
|------+------|------|
| Org  | 学习 | 基础 |
#+end_example

常用操作：

- =C-c |=：把区域转换为表格，或创建空表格。
- =TAB=：移动到下一个单元格并重新对齐。
- =S-TAB=：移动到上一个单元格。
- =M-LEFT/RIGHT=：移动列；=M-UP/DOWN=：移动行。
- =C-c C-c=：在表格中重新对齐当前表格；有公式时也会触发相应更新。

启用 =evil-org= 后，normal state 中也可用 =M-h/l= 移动列、=M-k/j= 移动行。

表格既可以作为普通笔记，也可以作为简单的数据表。复杂计算和程序化数据
处理再交给 Babel。

** 代码、引用与示例块

短代码可以使用 =~code~= 或 =\code=；需要保留格式的内容使用特殊块：

#+begin_example
#+begin_quote
这是一段引用。
#+end_quote

#+begin_src emacs-lisp
(message "hello")
#+end_src
#+end_example

源码块的编辑和执行属于 Org Babel，见后面的“Org Babel：让文档成为可执行
源码”。这里先记住：=C-c '= 编辑当前源码块，=C-c C-v t= 提取源码，
=C-c C-v e= 执行源码块。

** 属性、抽屉与文档元数据

文档开头的 =#+= 行是元数据或设置；标题下的属性可以给结构化内容附加字段。

#+begin_example
#+TITLE: 我的笔记
#+AUTHOR: Maeiee

,* 项目
:PROPERTIES:
:OWNER: Maeiee
:END:
#+end_example

抽屉通常保存属性或日志，不参与正文阅读。常用元数据包括 =#+TITLE=、
=#+AUTHOR=、=#+DATE=、=#+OPTIONS=、=#+PROPERTY=；本仓库的源码块默认参数
就通过 =#+PROPERTY: header-args:emacs-lisp ...= 设置。

** 在文档中定位

除了标题导航，还可以用这些方式快速定位：

- =C-c C-j=：按标题路径跳转。
- =C-c /=：按条件构建稀疏树，只显示匹配内容及其上下文。
- =C-c C-c=：在链接、标签、复选框等上下文中执行对应操作。
- =C-x n s=：收窄到当前子树；=C-x n w=：恢复完整视图。

启用 =evil-org= 后，本配置把 Evil normal state 的结构导航分成两层：

- =C-j= / =C-k=：下一个 / 上一个标题。
- =gj= / =gk=：下一个 / 上一个 Org element，保留 =evil-org= 的默认行为。
- =gh= / =gl=：移动到父级 / 子级 Org element。
- =gH=：跳到最近的顶层标题。

这里的 element 可以是段落、列表项、表格行或源码块，不一定只指标题；需要
精确地按标题导航时，使用 =C-j/C-k= 或原生的 =C-c C-n/p=。同级标题和父级
标题仍可分别使用 =C-c C-f/b= 与 =C-c C-u=。

当文档变长时，优先使用标题、搜索、稀疏树和收窄，而不是依靠滚动查找。

* 需要理解的概念

- Org 文档是源码；generated Elisp 是构建产物。
- tangle 面向机器执行，export 面向人类阅读。
- 一个模块只承担一个主题，文件名前缀同时表达加载顺序。

* 配置

** Org 文档的阅读与编辑体验

先把 Org 当作一种日常编辑环境来配置：打开文档时自动进入 Org Mode，阅读时保留清晰的层级与排版，编辑源码块时则尽量尊重原始代码的缩进。

Org 默认只把 ASCII 空白和标点作为行内强调标记的边界，因此中文，=代码=。这类写法不会触发 =org-hide-emphasis-markers=。下面把常见的
中文全角标点加入强调标记的前后边界；标点集合单独做成变量，日后可以通过 Customize 或直接修改该变量来扩展。

视觉软换行默认优先在空白处断行，这会把没有空格的连续中文误当成一个长词。
这里允许 Emacs 按字符类别在汉字之间断行；通过 Customize 设置该选项还会加载 =kinsoku=，避免逗号、句号等中文标点出现在视觉行首。

#+begin_src emacs-lisp
;; Org 是 Emacs 内置功能，不需要通过包管理器安装。
(defun maeiee-org--configure-cjk-emphasis-boundaries ()
  "Allow CJK punctuation around Org emphasis markers."
  (let ((components (copy-sequence org-emphasis-regexp-components)))
    ;; Remove our own punctuation before adding it so reloading stays idempotent.
    (dolist (index '(0 1))
      (setf (nth index components)
            (let ((component (nth index components)))
              (dolist (char (string-to-list maeiee-org-cjk-emphasis-punctuation))
                (setq component
                      (replace-regexp-in-string
                       (regexp-quote (char-to-string char)) ""
                       component t t)))
              (concat component maeiee-org-cjk-emphasis-punctuation))))
    ;; Org computes `org-emph-re' and `org-verbatim-re' from this variable.
    (org-set-emph-re 'org-emphasis-regexp-components components)))

(defcustom maeiee-org-cjk-emphasis-punctuation
  "，。！？；：、（）【】「」『』《》〈〉“”‘’〔〕［］｛｝…——"
  "CJK punctuation allowed next to Org emphasis markers."
  :type 'string
  :group 'org-appearance
  :set (lambda (symbol value)
         (set-default symbol value)
         ;; The setter may run before Org has been loaded.
         (when (and (boundp 'org-emphasis-regexp-components)
                    (fboundp 'org-set-emph-re))
           (maeiee-org--configure-cjk-emphasis-boundaries))))

(use-package org
  :ensure nil
  ;; 打开 .org 文件时自动启用 org-mode。
  :mode ("\\.org\\'" . org-mode)
  ;; 设置 Org Mode 的默认行为。
  :custom
  ;; 启用标题和内容的缩进显示，让层级结构更清晰。
  (org-startup-indented t)
  ;; 允许视觉软换行在中文字符之间选择断点，并遵循中文标点禁则。
  (word-wrap-by-category t)
  ;; 隐藏粗体、斜体等强调标记，只显示排版后的文字。
  (org-hide-emphasis-markers t)
  ;; 将 Org 实体（例如特殊字符）渲染成更易读的形式。
  (org-pretty-entities t)
  ;; 在 Org 源码块中使用对应语言的语法高亮。
  (org-src-fontify-natively t)
  ;; 让源码块中的 Tab 键遵循对应语言的缩进行为。
  (org-src-tab-acts-natively t)
  ;; 编辑源码块时不额外添加缩进，保持源码原本的列位置。
  (org-edit-src-content-indentation 0)
  ;; 设置标题循环时，标题之间保留一行分隔空白。
  (org-cycle-separator-lines 1)
  ;; 向通用 Imenu Outline 暴露最多八级 Org 标题。
  (org-imenu-depth 8)
  :config
  ;; 重新生成强调正则，使中文标点也能包围 =...=、~...~ 等行内标记。
  (maeiee-org--configure-cjk-emphasis-boundaries))
#+end_src

** Evil Org Mode：让 Org 使用 Evil 风格

=evil-collection= 主要负责 Agenda、Dired 和 Help 等特殊界面的 Evil 集成；
Org 文档本身的结构导航由 =evil-org= 提供。启用后，=evil-org-mode= 只在 Org 缓冲区增加 normal、visual 和 insert 状态下的 Org 专用操作，不会覆盖原生的 =C-c= 前缀命令，因此 Emacs 风格与 Evil 风格可以并存。

本仓库已经在 =00-package.org= 中配置了 MELPA，下面的 =use-package= 会在需要时安装 =evil-org=。=evil-org-agenda= 则为 Agenda 缓冲区补充相应的 Evil 键位。

考虑到 =[= / =]= 不适合作为高频键位，本配置把更顺手的 =C-j/C-k= 注册为标题 motion，并同时用于 normal、visual 和 motion state；=gj/gk= 则保持 =evil-org= 默认的 element 导航。

#+begin_src emacs-lisp
(use-package evil-org
  :ensure t
  :after (org evil)
  ;; 只在 Org 缓冲区启用 Evil Org 键位。
  :hook (org-mode . evil-org-mode)
  :config
  ;; 保留导航、插入、回车、文本对象和 Org 的附加操作。
  (evil-org-set-key-theme
   '(navigation insert return textobjects additional))
  ;; C-j/C-k 专门跳转标题，gj/gk 继续使用 evil-org 的 element 导航。
  (evil-define-key '(normal visual motion) 'evil-org-mode
    (kbd "C-j") #'org-next-visible-heading
    (kbd "C-k") #'org-previous-visible-heading)
  ;; 为 Org Agenda 设置对应的 Evil 键位。
  (require 'evil-org-agenda)
  (evil-org-agenda-set-keys))
#+end_src

** Org Babel：让文档成为可执行源码

文学编程的关键不只是把代码放进 Org，而是让同一份文档同时服务于阅读、编辑和构建。这里启用 Emacs Lisp 与 Shell 两种 Babel 语言，并把初始化代码独立出来，便于按概念阅读和修改。

#+begin_src emacs-lisp
;; Org 加载后，再启用对应的 Babel 语言。
(with-eval-after-load 'org
  ;; 确保 Emacs Lisp 代码块的 Babel 支持已加载。
  (require 'ob-emacs-lisp)
  ;; 注册 Org Babel 支持的语言。
  (org-babel-do-load-languages
   ;; 修改 Org Babel 的语言配置变量。
   'org-babel-load-languages
   ;; 启用 Emacs Lisp 和 Shell 代码块。
   '((emacs-lisp . t)
     (shell . t))))
#+end_src

** 用快捷键连接 Org 的日常工作流

Org 的配置还需要和仓库自身的工作流接上：Capture 与 Agenda 面向内容，tangle 与 reload 面向配置。把它们放在同一个快捷键主题下，读者可以直接看出“写内容”和“维护配置”如何共享 Org 入口。

#+begin_src emacs-lisp
;; 等 general 包加载后，再注册 Org 相关的 leader 快捷键。
(with-eval-after-load 'general
  ;; 在 maeiee 的 leader 键下创建 Org 快捷键分组。
  (maeiee-leader
    ;; "o" 本身只是分组前缀，不绑定具体命令。
    "o" '(:ignore t :which-key "org")
    ;; 使用 "o c" 调用 Org Capture。
    "o c" '(org-capture :which-key "capture")
    ;; 使用 "o a" 打开 Org Agenda。
    "o a" '(org-agenda :which-key "agenda")
    ;; 使用 "o t" tangle 当前配置模块。
    "o t" '(maeiee-tangle-current-module :which-key "tangle module")
    ;; 使用 "o r" 重载当前配置模块。
    "o r" '(maeiee-reload-current-module :which-key "reload module")))
#+end_src

* 动手验证

1. 在包含多个标题、段落和列表项的 Org 文档中进入 normal state，使用
   =C-j/C-k= 验证光标只在标题间移动，再用 =gj/gk= 验证 element 导航。
2. 按 =SPC w o= 打开通用 Outline，确认其中包含当前 Org 文档的多级标题。
3. 在当前模块源码块内按 =C-c '=，进入专用 Emacs Lisp 编辑缓冲区。
4. 按 =C-c C-v t= 了解原生 tangle；本仓库日常则用 =SPC o t=。
5. 修改一个无副作用变量，保存后按 =SPC m=，点击“重载当前模块”，验证立即生效。
