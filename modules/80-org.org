#+PROPERTY: header-args:emacs-lisp :results silent :comments link
#+STARTUP: overview

* 本章目标

建立适合文学编程的 Org 默认行为，并提供打开目录、tangle、重载等日常命令。

* 需要理解的概念

- Org 文档是源码；generated Elisp 是构建产物。
- tangle 面向机器执行，export 面向人类阅读。
- 一个模块只承担一个主题，文件名前缀同时表达加载顺序。

* 配置

** Org 文档的阅读与编辑体验

先把 Org 当作一种日常编辑环境来配置：打开文档时自动进入
Org Mode，阅读时保留清晰的层级与排版，编辑源码块时则尽量尊重原始代码的缩进。

#+begin_src emacs-lisp
;; Org 是 Emacs 内置功能，不需要通过包管理器安装。
(use-package org
  :ensure nil
  ;; 打开 .org 文件时自动启用 org-mode。
  :mode ("\\.org\\'" . org-mode)
  ;; 设置 Org Mode 的默认行为。
  :custom
  ;; 启用标题和内容的缩进显示，让层级结构更清晰。
  (org-startup-indented t)
  ;; 隐藏粗体、斜体等强调标记，只显示排版后的文字。
  (org-hide-emphasis-markers t)
  ;; 将 Org 实体（例如特殊字符）渲染成更易读的形式。
  (org-pretty-entities t)
  ;; 在 Org 源码块中使用对应语言的语法高亮。
  (org-src-fontify-natively t)
  ;; 让源码块中的 Tab 键遵循对应语言的缩进行为。
  (org-src-tab-acts-natively t)
  ;; 编辑源码块时不额外添加缩进，保持源码原本的列位置。
  (org-edit-src-content-indentation 0)
  ;; 设置标题循环时，标题之间保留一行分隔空白。
  (org-cycle-separator-lines 1))
#+end_src

** Org Babel：让文档成为可执行源码

文学编程的关键不只是把代码放进 Org，而是让同一份文档同时服务于
阅读、编辑和构建。这里启用 Emacs Lisp 与 Shell 两种 Babel 语言，并把
初始化代码独立出来，便于按概念阅读和修改。

#+begin_src emacs-lisp
;; Org 加载后，再启用对应的 Babel 语言。
(with-eval-after-load 'org
  ;; 确保 Emacs Lisp 代码块的 Babel 支持已加载。
  (require 'ob-emacs-lisp)
  ;; 注册 Org Babel 支持的语言。
  (org-babel-do-load-languages
   ;; 修改 Org Babel 的语言配置变量。
   'org-babel-load-languages
   ;; 启用 Emacs Lisp 和 Shell 代码块。
   '((emacs-lisp . t)
     (shell . t))))
#+end_src

** 用快捷键连接 Org 的日常工作流

Org 的配置还需要和仓库自身的工作流接上：Capture 与 Agenda 面向内容，
tangle 与 reload 面向配置。把它们放在同一个快捷键主题下，读者可以直接
看出“写内容”和“维护配置”如何共享 Org 入口。

#+begin_src emacs-lisp
;; 等 general 包加载后，再注册 Org 相关的 leader 快捷键。
(with-eval-after-load 'general
  ;; 在 maeiee 的 leader 键下创建 Org 快捷键分组。
  (maeiee-leader
    ;; "o" 本身只是分组前缀，不绑定具体命令。
    "o" '(:ignore t :which-key "org")
    ;; 使用 "o c" 调用 Org Capture。
    "o c" '(org-capture :which-key "capture")
    ;; 使用 "o a" 打开 Org Agenda。
    "o a" '(org-agenda :which-key "agenda")
    ;; 使用 "o t" tangle 当前配置模块。
    "o t" '(maeiee-tangle-current-module :which-key "tangle module")
    ;; 使用 "o r" 重载当前配置模块。
    "o r" '(maeiee-reload-current-module :which-key "reload module")))
#+end_src

* 动手验证

1. 在当前模块源码块内按 =C-c '=，进入专用 Emacs Lisp 编辑缓冲区。
2. 按 =C-c C-v t= 了解原生 tangle；本仓库日常则用 =SPC o t=。
3. 修改一个无副作用变量，保存后按 =SPC m=，点击“重载当前模块”，验证立即生效。

* 维护笔记

- 修改后保存，本仓库会自动 tangle 当前模块。
- 想立即应用本章，执行 =M-x maeiee-reload-current-module=。
- 生成的 =80-org.el= 位于 =generated/=，不要直接编辑。
