#+TITLE: 50 项目工作空间：建立边界、查找内容与浏览文件树
#+PROPERTY: header-args:emacs-lisp :results silent :comments link
#+STARTUP: overview

* 本章目标

先用 Emacs 内置的 project.el 建立项目边界，再让 Treemacs 把这个边界呈现为
可按需开关的左侧文件树。项目切换、项目内查找和文件树浏览因此共享同一个
工作上下文，不需要引入第二套项目管理框架。

* 需要理解的概念

- project.el 是项目协议：后端负责判断目录边界，Git 仓库是最常见的项目来源。
- 项目命令把“当前目录”升级为有边界的工作上下文，供文件、缓冲区和搜索命令
  共同使用。
- Treemacs 是这个上下文的一种可视化入口，不取代普通编辑窗口，也不拥有另一份
  项目定义。
- =treemacs-evil= 只负责侧边栏内的状态和导航手感；项目发现仍由 project.el
  与 Treemacs 的公开集成命令完成。

* 用 project.el 建立工作边界

项目协议先于可视化文件树加载。这里声明项目切换时可发现的常用动作，并建立
=SPC p= 命名空间。

#+begin_src emacs-lisp
(use-package project
  :ensure nil
  :custom
  ;; 切换项目后显示文件、搜索、Dired 与 Eshell 四个常用入口。
  (project-switch-commands
   '((project-find-file "Find file" ?f)
     (project-find-regexp "Find regexp" ?g)
     (project-dired "Dired" ?d)
     (project-eshell "Eshell" ?e))))

(with-eval-after-load 'general
  ;; General 就绪后建立稳定的项目二级菜单。
  (maeiee-leader
    "p" '(:ignore t :which-key "project")
    "p p" '(project-switch-project :which-key "switch")
    "p f" '(project-find-file :which-key "find file")
    "p g" '(project-find-regexp :which-key "grep")
    "p b" '(project-switch-to-buffer :which-key "buffer")
    "p d" '(project-dired :which-key "dired")))
#+end_src

* 在左侧浏览项目文件树

Treemacs 沿用 project.el 识别出的工作空间，只声明日常需要调整的窗口、跟随和
刷新行为。侧边栏保持按需加载，避免在不使用文件树时增加启动工作。

#+begin_src emacs-lisp
(use-package treemacs
  :commands (treemacs)
  :custom
  ;; 把项目文件树固定显示在左侧。
  (treemacs-position 'left)
  ;; 使用适合常见项目名称的初始宽度。
  (treemacs-width 32)
  ;; 第一次打开时定位并展开当前文件所在项目。
  (treemacs-follow-after-init t)
  (treemacs-expand-after-init t)
  :config
  ;; 编辑器切换文件时，让文件树同步选中当前文件。
  (treemacs-follow-mode 1)
  ;; 监听磁盘变化，及时刷新新建、删除或改名的文件。
  (treemacs-filewatch-mode 1))
#+end_src

* 项目感知的文件树开关

直接第一次调用 =treemacs= 时，空工作区会询问项目根目录。Maeiee 的包装命令
复用 Treemacs 的公开项目命令：首次打开自动加入当前 project.el 项目，已经显示
时仍调用原生 toggle 关闭。

#+begin_src emacs-lisp
(defun maeiee-treemacs-toggle ()
  "Toggle the Treemacs sidebar, adding the current project when needed."
  (interactive)
  ;; 按键首次触发时才加载 Treemacs，避免增加无关启动工作。
  (require 'treemacs)
  ;; 已经显示时关闭；否则加入当前项目并显示文件树。
  (if (eq (treemacs-current-visibility) 'visible)
      (treemacs)
    (treemacs-add-and-display-current-project)))
#+end_src

* 统一侧边栏导航与项目入口

#+begin_src emacs-lisp
(use-package treemacs-evil
  :after (treemacs evil))

(with-eval-after-load 'general
  ;; 不增加新的 Leader 一级菜单，只扩展已有的项目菜单。
  (maeiee-leader
    "p t" '(maeiee-treemacs-toggle :which-key "toggle file tree")))
#+end_src

* 动手验证

1. 在本配置仓库中按 =SPC p f= 查找文件，再用 =SPC p b= 切换项目缓冲区。
2. 执行 =M-x project-remember-projects-under= 扫描代码根目录，并用 =SPC p p=
   切换项目。
3. 在 Git 项目中按 =SPC p t=，确认左侧直接出现当前项目而不询问根目录。
4. 在文件树中用 =j/k= 移动、=RET= 打开文件，确认编辑窗口正常保留。
5. 再按 =SPC p t= 关闭文件树；新建或删除临时文件时确认目录会自动刷新。

* 维护笔记

- 项目能力优先复用 project.el 协议；文件树只是消费者，不维护第二份项目清单。
- 文件树不设置额外的全局快捷键，只通过已有的 =SPC p t= 暴露。
- 修改后保存，本仓库会自动 tangle 当前模块。
- 想立即应用本章，执行 =M-x maeiee-reload-current-module=。
- 生成的 =50-project-workspace.el= 位于 =generated/=，不要直接编辑。
