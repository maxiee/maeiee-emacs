#+TITLE: 33 Transient：为 Leader 增加配置管理二级菜单
#+PROPERTY: header-args:emacs-lisp :results silent :comments link
#+STARTUP: overview

* 本章目标

保持 =SPC= 的原有一级 Leader 菜单不变，只增加一个 =m=（Maeiee 配置）入口。按 =SPC m= 后，在窗口底部显示配置管理二级菜单；其中列出所有文学配置文件与常用管理操作，既能按提示键选择，也能用鼠标点击。

* 需要理解的概念

- Transient 是 Magit 同款的临时命令面板，默认显示在窗口底部。
- 菜单项是真正的按钮；单击项目名称就会执行对应命令。
- Insert state 中的空格仍然只是空格，不会打断文字输入。
- =SPC= 后原有的 file、buffer、window、project、Git、Org 等一级分类保持不变。
- 不使用 Evil normal state 时，也可以用 =C-c SPC m= 打开同一个二级菜单。

(defun maeiee-config-menu-find-file ()
  "Choose and open a human-maintained Org file from this repository."
  (interactive)
  (let* ((fixed-files '("README.org"
                        "bootstrap.org"
                        "docs/ROADMAP.org"
                        "book/book.org"))
         (module-files
          (mapcar (lambda (file)
                    (file-relative-name file maeiee-emacs-root))
                  (maeiee--module-files)))
         (relative-file
          (completing-read "配置文件: "
                           (append fixed-files module-files)
                           nil t)))
    (maeiee-config-menu--open-file relative-file)))

(defun maeiee-config-menu-magit-status ()
  "Open Magit status for the configuration repository."
  (interactive)
  (let ((default-directory maeiee-emacs-root))
    (call-interactively #'magit-status)))

(defun maeiee-config-menu--compile-target (target)
  "Run make TARGET from the configuration repository."
  (let ((default-directory maeiee-emacs-root))
    (compile (format "make %s" target))))

(defun maeiee-config-menu-check ()
  "Tangle and syntax-check every configuration module."

(defun maeiee-config-menu-doctor ()
  "Run the repository environment diagnostics."

* 动手验证

1. 回到 Evil normal state，按 =SPC=，确认原有一级 Leader 分类仍然存在，并新增 =m=（Maeiee 配置）。
2. 按 =m= 进入配置管理二级菜单，再用鼠标单击 =README 总览=。
3. 再按 =SPC m=，单击任一编号模块，确认打开相应 Org 文档。
4. 在模块中修改并保存后，按 =SPC m= 再单击 =重载当前模块=。
5. 二级菜单中也可直接按菜单项左侧显示的键；按 =q= 或 =C-g= 关闭。

* 维护笔记

- Transient 原生支持鼠标单击，不需要另写 GUI 框架。
- 新增模块后，要同时把它加入本菜单和 =book/book.org=。
- 修改后保存，本仓库会自动 tangle 当前模块。
- 生成的 =33-menu.el= 位于 =generated/=，不要直接编辑。
